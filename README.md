# EndlessHospitalTutorial

**Endless Hospital** is a **Unity 3D beginner-friendly tutorial project**.
This course guides learners through building an **Endless Runner game** from scratch while understanding the core concepts of Unity.

**《無盡醫院》** 是一個為 **Unity 3D 初學者** 設計的教學專案，
透過實作「無盡跑酷（Endless Runner）」遊戲，學習 Unity 的基礎與實戰流程。

---

## 🎮 Project Type｜專案類型

* Endless Runner Game｜無盡跑酷遊戲
* Unity 3D Tutorial Project｜Unity 3D 教學專案
* Single Player｜單人遊戲

---

## 🎯 Learning Goals｜教學目標

This project is designed for **Unity beginners** and covers:

* Unity editor basics and workflow
* 3D scene creation and management
* Character movement and runner mechanics
* Endless level generation 
* Collision detection and basic game logic
* Game flow control (Start / Game Over / Restart)
* Basic performance and project structure concepts

本專案適合 **Unity 新手**，內容包含：

* Unity 介面與基本操作
* 3D 場景建立與管理
* 角色移動與跑酷邏輯
* 無盡關卡生成
* 碰撞判定與基礎遊戲邏輯
* 遊戲流程控制（開始 / 結束 / 重來）
* 基本效能與專案結構概念

---

## 🏥 Game Background｜遊戲背景

You are trapped inside an **abandoned hospital that never ends**.
The corridors stretch endlessly, and the environment becomes more disturbing as you move forward.
Your only option is to **keep running**.

你被困在一間**無限延伸的廢棄醫院**中。
走廊不斷生成，氣氛逐漸變得壓迫而詭異。
你唯一能做的事情，就是 **不停地向前奔跑**。
